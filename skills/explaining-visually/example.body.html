Move session tokens into httpOnly cookies

Today any script on the page can read the session token. After this change only the browser can.

Should the mobile app move to cookies too? Decides whether step 3 can drop the bearer path entirely.
  1. Move it tooOne auth path; needs an app release first.
  2. Keep bearer for mobileTwo auth paths stay, step 3 shrinks.
Does any third-party integration read the token from the login response body?
  • WhyAn XSS bug today means a stolen session.
  • What changesLogin sets a cookie; the client stops touching the token.
  • Size3 files, one migration step, no schema change.
